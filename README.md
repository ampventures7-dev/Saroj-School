# Saroj Mehta International School (SMISK), Karanjani, Dapoli

Official modern responsive website for **Saroj Mehta International School (SMISK)**, Karanjani, Dapoli (Ratnagiri, Maharashtra) — managed by Santoshbhai Mehta Foundation.

## Overview
This modern institutional website features a clean, responsive design inspired by modern educational web standards:
- **Interactive Hero Carousel & Circulars Board:** Real-time school circulars, announcements, and notices with modal reader.
- **Academic Sections:** Pre-Primary, Primary, and Secondary wings curriculum details and facilities.
- **Gallery & Achievements:** Filterable campus life, sports, and cultural event galleries.
- **Admissions Portal:** Dynamic 2026-27 admission enquiry form with instant validation and modal dialogue.
- **Mobile Responsive Header & Navigation:** Tailored mobile header with official emblem crest, quick-action buttons, and slide drawer navigation.

## Tech Stack
- **HTML5 & Vanilla CSS3**
- **JavaScript (ES6+)**
- **Font Awesome 6 & Google Fonts (Inter / Outfit / Cinzel)**

## Running Locally
You can view the site locally with any static web server:
```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```
Then visit `http://localhost:8080/`.
